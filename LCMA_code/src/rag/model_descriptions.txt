Model: ARIMA.
Type: Statistical.
Description: ARIMA (AutoRegressive Integrated Moving Average) is suitable for stationary or differenced stationary time series. It models autocorrelations and is best for data without strong seasonality.
Supported features: trend: yes; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: no.
Key parameters: p (Order of autoregression); d (Degree of differencing); q (Order of moving average).

Model: ETS.
Type: Statistical.
Description: ETS (Error, Trend, Seasonality) models decompose time series into these three components. They are effective for short univariate time series with clear trend and/or seasonality, offering fast and interpretable forecasting.
Supported features: trend: yes; seasonality: yes; nonlinearity: no; short series: yes; high frequency: no; intermittent: no.
Key parameters: trend (Additive or multiplicative trend component); seasonal (Additive or multiplicative seasonal component); damped (Whether to dampen the trend).

Model: Theta.
Type: Statistical.
Description: The Theta model is a simple and robust forecasting method that performs well for time series with trend and low noise. It’s well-known from the M3 competition.
Supported features: trend: yes; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: no.
Key parameters: theta (Controls the curvature of the time series).

Model: LSTM.
Type: DeepLearning.
Description: LSTM (Long Short-Term Memory) networks are a type of RNN capable of learning long-term dependencies. They are effective for capturing complex, nonlinear temporal dynamics.
Supported features: trend: yes; seasonality: yes; nonlinearity: yes; short series: no; high frequency: yes; intermittent: no.
Key parameters: hidden_size (Number of hidden units); layers (Number of LSTM layers); dropout (Dropout rate for regularization).

Model: UnobservedComponents.
Type: Statistical.
Description: Unobserved Components model decomposes a time series into trend, seasonal, and cyclical components, optionally with stochastic volatility.
Supported features: trend: yes; seasonality: yes; nonlinearity: no; short series: yes; high frequency: no; intermittent: no.
Key parameters: level (Local level component); trend (Local trend); seasonal (Seasonal component).

Model: xgboost.
Type: MachineLearning.
Description: XGBoost is a gradient boosting algorithm optimized for performance and speed. It can handle nonlinearity and works well when using extracted features from time series.
Supported features: trend: yes; seasonality: yes; nonlinearity: yes; short series: yes; high frequency: yes; intermittent: no.
Key parameters: n_estimators (Number of boosting rounds); max_depth (Maximum depth of a tree); learning_rate (Boosting learning rate).

Model: lightgbm.
Type: MachineLearning.
Description: LightGBM is a highly efficient gradient boosting framework that supports categorical features and works well with large datasets. Suitable for engineered time series features.
Supported features: trend: yes; seasonality: yes; nonlinearity: yes; short series: yes; high frequency: yes; intermittent: no.
Key parameters: num_leaves (Number of leaves in one tree); learning_rate (Boosting learning rate); n_estimators (Number of boosting rounds).

Model: svm.
Type: MachineLearning.
Description: Support Vector Machines are effective in high-dimensional feature spaces and can capture nonlinearities when using kernels. Requires well-engineered time series features.
Supported features: trend: no; seasonality: no; nonlinearity: yes; short series: yes; high frequency: no; intermittent: no.
Key parameters: kernel (Type of kernel (linear, rbf, etc.)); C (Regularization parameter); gamma (Kernel coefficient).

Model: deepAR.
Type: DeepLearning.
Description: DeepAR is an autoregressive recurrent neural network that models probabilistic forecasts and captures item-level and group-level patterns across series.
Supported features: trend: yes; seasonality: yes; nonlinearity: yes; short series: no; high frequency: yes; intermittent: no.
Key parameters: context_length (Length of historical window); prediction_length (Forecast horizon); num_layers (Number of RNN layers).

Model: NeuralProphet.
Type: Hybrid.
Description: NeuralProphet extends Facebook Prophet by integrating AR-Net. It supports trend, seasonality, holidays, and regressors, combining interpretability with neural networks.
Supported features: trend: yes; seasonality: yes; nonlinearity: yes; short series: yes; high frequency: yes; intermittent: yes.
Key parameters: n_changepoints (Number of trend changepoints); seasonality_mode (Additive or multiplicative); epochs (Number of training epochs).

Model: ARCH.
Type: Statistical.
Description: ARCH (Autoregressive Conditional Heteroskedasticity) models are used for time series where the variance changes over time, typically in financial domains.
Supported features: trend: no; seasonality: no; nonlinearity: yes; short series: yes; high frequency: no; intermittent: no.
Key parameters: lags (Number of lags for ARCH terms).

Model: AverageValueNaive.
Type: Baseline.
Description: A naive forecasting method that simply averages past values. Useful as a baseline model for comparison.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: no.

Model: CrostonClassic.
Type: Intermittent.
Description: Croston's method is specialized for intermittent demand forecasting. It separates estimation of demand size and demand intervals.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: yes.
Key parameters: alpha (Smoothing parameter).

Model: ADIDA.
Type: Intermittent.
Description: ADIDA (Aggregate-Disaggregate Intermittent Demand Approach) transforms intermittent series into a continuous one by aggregation, then applies a standard forecasting model.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: yes.
Key parameters: aggregation_level (Time aggregation window).

Model: IMAPA.
Type: Intermittent.
Description: IMAPA is an extension of the ADIDA model using multiple aggregation levels. It aims to improve forecasting accuracy in intermittent time series.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: yes.
Key parameters: max_agg (Maximum aggregation level).

Model: TSB.
Type: Intermittent.
Description: TSB (Teunter-Syntetos-Babai) method modifies Croston by updating both the demand size and probability of demand occurrence, offering better bias control.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: yes.
Key parameters: alpha (Demand smoothing); beta (Occurrence smoothing).

Model: SBA.
Type: Intermittent.
Description: SBA (Syntetos-Boylan Approximation) corrects the bias in Croston’s method by modifying the updating formula for more accurate forecasts.
Supported features: trend: no; seasonality: no; nonlinearity: no; short series: yes; high frequency: no; intermittent: yes.
Key parameters: alpha (Smoothing parameter).
