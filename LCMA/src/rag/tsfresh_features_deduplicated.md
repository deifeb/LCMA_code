# tsfresh 时间序列特征提取全面指南

tsfresh (Time Series Feature extraction based on scalable hypothesis tests) 是一个强大的 Python 库，专门用于从时间序列数据中自动提取有意义的特征。本文档详细解释所有 tsfresh 特征提取函数的原理、类型、使用场景和适用性。

## 基础统计特征

### 1. abs_energy(x)
- **特征解释**：计算时间序列的绝对能量，即所有平方值的总和。
- **计算公式**：$E = \sum_{i=1}^{n} x_i^2$
- **特征类型**：能量特征
- **适用性**：
  - 适用于衡量信号的整体强度或波动程度
  - 对异常检测和活动识别特别有效
  - 不受时间序列长度影响的特征
- **示例**：对于序列 [1, 2, 3]，abs_energy = 1² + 2² + 3² = 14

### 35. maximum(x)
- **特征解释**：计算时间序列的最大值。
- **计算公式**：$\max(x)$
- **特征类型**：统计特征
- **适用性**：
  - 捕捉时间序列的极值特性
  - 在异常检测中用于识别峰值
  - 适合需要了解数据范围上界的场景
- **示例**：对于序列 [1, 5, 3, 8, 4]，maximum = 8

### 36. mean(x)
- **特征解释**：计算时间序列的算术平均值。
- **计算公式**：$\mu = \frac{1}{n}\sum_{i=1}^{n} x_i$
- **特征类型**：统计特征
- **适用性**：
  - 描述时间序列的中心趋势
  - 作为其他多种特征计算的基准值
  - 几乎所有时间序列分析的基础特征
- **示例**：对于序列 [1, 2, 3, 4, 5]，mean = 3

### 40. median(x)
- **特征解释**：计算时间序列的中位数，即排序后中间位置的值。
- **计算公式**：数据排序后的中间值
- **特征类型**：统计特征
- **适用性**：
  - 对异常值不敏感的中心趋势度量
  - 适用于可能包含离群值的数据
  - 非对称分布的鲁棒性中心测量
- **示例**：对于序列 [1, 3, 5, 7, 9]，median = 5

### 41. minimum(x)
- **特征解释**：计算时间序列的最小值。
- **计算公式**：$\min(x)$
- **特征类型**：统计特征
- **适用性**：
  - 捕捉时间序列的极值特性
  - 在异常检测中用于识别低谷
  - 适合需要了解数据范围下界的场景
- **示例**：对于序列 [5, 3, 8, 1, 4]，minimum = 1

### 48. quantile(x, q)
- **特征解释**：计算时间序列的q分位数，q为0到1之间的数值。
- **计算公式**：数据按升序排列后的第q*N位置的值
- **特征类型**：统计特征
- **适用性**：
  - 描述数据分布的不同部分
  - 对异常值比均值更稳健
  - 适用于构建数据分布的整体概况
- **参数**：q - 分位数（如0.25代表第一四分位数）
- **示例**：对于序列 [1, 2, 3, 4, 5]，quantile(x, 0.25) = 2

### 56. standard_deviation(x)
- **特征解释**：计算时间序列值的标准差，衡量数据点围绕均值的分散程度。
- **计算公式**：$\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i-\mu)^2}$
- **特征类型**：统计特征
- **适用性**：
  - 衡量时间序列的波动性或稳定性
  - 在金融时间序列中用于衡量风险或波动率
  - 用于检测异常波动周期
- **示例**：对于序列 [1, 2, 3, 4, 5]，standard_deviation ≈ 1.414

### 59. sum_values(x)
- **特征解释**：计算时间序列所有值的总和。
- **计算公式**：$\sum_{i=1}^{n} x_i$
- **特征类型**：统计特征
- **适用性**：
  - 适用于累积型数据，如总销售额或总功耗
  - 在比较不同长度时间序列时需谨慎使用
  - 适合需要总量而非平均值的场景
- **示例**：对于序列 [1, 2, 3, 4, 5]，sum_values = 15

### 63. variance(x)
- **特征解释**：计算时间序列的方差，衡量数据点的离散程度。
- **计算公式**：$\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i-\mu)^2$
- **特征类型**：统计特征
- **适用性**：
  - 衡量时间序列数据的离散程度
  - 标准差的平方，提供相同信息但不同尺度
  - 在需要平方差异加权的情况下使用
- **示例**：对于序列 [1, 2, 3, 4, 5]，variance = 2

### 30. length(x)
- **特征解释**：返回时间序列的长度（数据点数量）。
- **计算公式**：数据点的数量
- **特征类型**：结构特征
- **适用性**：
  - 用于数据预处理和验证
  - 在需要考虑样本量的分析中很重要
  - 辅助其他特征生成的参考值
- **示例**：对于序列 [1, 2, 3, 4, 5]，length = 5

## 分布特征

### 26. kurtosis(x)
- **特征解释**：计算时间序列的峰度，衡量分布的"尖峭度"或"厚尾性"。
- **计算公式**：$Kurt = \frac{\sum_{i=1}^{n}(x_i-\mu)^4}{n\sigma^4} - 3$
- **特征类型**：分布特征
- **适用性**：
  - 检测时间序列分布中的极端值情况
  - 高峰度表明数据有厚尾（极值发生频率高）
  - 金融时间序列中用于风险分析
- **示例**：正态分布的峰度为0（减去3后）；高于0表示比正态分布更尖峭

### 54. skewness(x)
- **特征解释**：计算时间序列的偏度，衡量分布的不对称性。
- **计算公式**：$Skew = \frac{\sum_{i=1}^{n}(x_i-\mu)^3}{n\sigma^3}$
- **特征类型**：分布特征
- **适用性**：
  - 检测分布的不对称性
  - 正偏度表示右侧尾部较长（正方向有极值）
  - 负偏度表示左侧尾部较长（负方向有极值）
- **示例**：对称分布的偏度为0；股票回报率通常呈负偏度

### 13. count_above_mean(x)
- **特征解释**：计算时间序列中高于均值的数据点数量。
- **计算公式**：高于均值的点的数量
- **特征类型**：分布特征
- **适用性**：
  - 分析时间序列的不对称性
  - 与序列长度结合使用，判断数据倾斜程度
  - 判断极值是否主导均值
- **示例**：对于序列 [1, 2, 3, 4, 10]，均值为4，count_above_mean = 2

### 14. count_below_mean(x)
- **特征解释**：计算时间序列中低于均值的数据点数量。
- **计算公式**：低于均值的点的数量
- **特征类型**：分布特征
- **适用性**：
  - 与count_above_mean互补，共同分析分布形态
  - 检测受极值影响的均值偏移
  - 判断数据偏离中心趋势的模式
- **示例**：对于序列 [1, 2, 3, 4, 10]，均值为4，count_below_mean = 3

### 50. ratio_beyond_r_sigma(x, r)
- **特征解释**：计算偏离均值超过r倍标准差的数据点比例。
- **计算公式**：$\frac{\text{偏离均值超过r倍标准差的点数}}{n}$
- **特征类型**：分布特征
- **适用性**：
  - 检测异常值或极端事件
  - 评估分布的尾部厚度
  - 常用r值为1, 2, 3（对应正态分布的68%, 95%, 99.7%规则）
- **参数**：r - 标准差的倍数
- **示例**：对于正态分布，ratio_beyond_2_sigma ≈ 0.05（5%的数据）

### 51. ratio_value_number_to_time_series_length(x)
- **特征解释**：计算唯一值数量与时间序列长度的比例。
- **计算公式**：$\frac{\text{唯一值数量}}{\text{序列长度}}$
- **特征类型**：分布特征
- **适用性**：
  - 检测时间序列的多样性或变化程度
  - 识别常量或离散值时间序列
  - 评估传感器精度或数据量化效应
- **示例**：对于序列 [1, 2, 2, 3, 3, 3]，ratio_value_number_to_time_series_length = 3/6 = 0.5

### 64. variance_larger_than_standard_deviation(x)
- **特征解释**：检测时间序列的方差是否大于标准差，通常为True（因为方差是标准差的平方）。
- **计算公式**：$variance > standard\_deviation$ 布尔值
- **特征类型**：分布特征
- **适用性**：
  - 作为数据验证检查
  - 当标准差小于1且方差更小时为False
  - 主要用于特征完整性检查
- **示例**：对于任何标准差大于1的分布，此特征为True

### 9. binned_entropy(x, max_bins)
- **特征解释**：将时间序列划分为若干个箱，然后计算基于这些箱的熵值。
- **计算公式**：$H = -\sum_{i=1}^{k} p_i \log(p_i)$，其中$p_i$是落入第i个箱的概率
- **特征类型**：分布特征
- **适用性**：
  - 衡量时间序列值分布的不确定性或随机性
  - 高熵值表示数据更均匀分布在不同箱中
  - 低熵值表示数据集中在少数几个箱中
- **参数**：max_bins - 最大箱数
- **示例**：均匀分布的序列熵值高，集中分布的序列熵值低

### 49. range_count(x, min, max)
- **特征解释**：计算时间序列中值落在[min, max]范围内的数据点数量。
- **计算公式**：min ≤ x ≤ max 的点的数量
- **特征类型**：分布特征
- **适用性**：
  - 评估特定范围内的数据密度
  - 检测阈值范围内的活动
  - 分析数据在特定区间的分布
- **参数**：min - 下限值；max - 上限值
- **示例**：对于序列 [1, 5, 3, 8, 4]，range_count(x, 3, 6) = 3

### 62. value_count(x, value)
- **特征解释**：计算特定值在时间序列中出现的次数。
- **计算公式**：x == value 的点的数量
- **特征类型**：分布特征
- **适用性**：
  - 检测特定事件或状态的频率
  - 识别重复模式或常量段
  - 分析离散值时间序列
- **参数**：value - 要计算的特定值
- **示例**：对于序列 [1, 2, 2, 3, 2]，value_count(x, 2) = 3

## 自相关特征

### 8. autocorrelation(x, lag)
- **特征解释**：在指定滞后值上计算时间序列的自相关系数。
- **计算公式**：$r_k = \frac{\sum_{i=k+1}^{n}(x_i-\mu)(x_{i-k}-\mu)}{\sum_{i=1}^{n}(x_i-\mu)^2}$
- **特征类型**：自相关特征
- **适用性**：
  - 检测时间序列中的季节性或周期性模式
  - 评估当前值与过去值的相关性
  - 帮助确定ARIMA模型的参数
- **参数**：lag - 滞后步数
- **示例**：周期性数据在周期长度的滞后处会有高自相关

### 10. c3(x, lag)
- **特征解释**：计算时间序列的非线性自相关（3点相关）。
- **计算公式**：$c3(x, lag) = \frac{1}{n-lag} \sum_{i=0}^{n-lag} x_i \cdot x_{i+lag}^2$
- **特征类型**：自相关特征
- **适用性**：
  - 检测非线性动态系统中的结构
  - 识别时间序列中的非线性依赖关系
  - 在金融时间序列分析中用于捕捉非线性模式
- **参数**：lag - 滞后步数
- **示例**：在具有非线性动态的系统中，c3可以捕捉到线性自相关方法无法检测的模式

### 3. agg_autocorrelation(x, param)
- **特征解释**：计算时间序列在不同滞后值上的自相关性，并应用指定的聚合函数。
- **计算公式**：对不同滞后值的自相关系数应用聚合函数（如均值、方差等）
- **特征类型**：自相关特征
- **适用性**：
  - 综合评估多个滞后值的自相关特性
  - 检测复杂的时间依赖结构
  - 简化对多个自相关值的分析
- **参数**：param - 包含滞后值列表和聚合函数
- **示例**：可以计算滞后1-10的自相关系数的平均值，提供整体自相关强度

### 45. partial_autocorrelation(x, param)
- **特征解释**：计算时间序列的偏自相关系数，用于评估直接关系，排除中间滞后的影响。
- **计算公式**：基于逆Durbin-Levinson递归或Yule-Walker方程
- **特征类型**：自相关特征
- **适用性**：
  - 确定AR(p)模型的阶数
  - 识别直接的时间依赖关系
  - 排除间接关系导致的虚假相关
- **参数**：param - 包含滞后值列表
- **示例**：在ARIMA建模中，显著的偏自相关截止值用于确定AR项数

### 32. longest_strike_above_mean(x)
- **特征解释**：计算时间序列中连续高于均值的最长序列长度。
- **计算公式**：连续高于均值点的最长子序列长度
- **特征类型**：连续性特征
- **适用性**：
  - 检测持续上升或高水平期
  - 识别时间序列中的稳定趋势
  - 分析数据的突发性或持续性
- **示例**：对于序列 [1, 2, 3, 1, 2, 6, 4, 5]，均值为3，longest_strike_above_mean = 3（最后三个值）

### 33. longest_strike_below_mean(x)
- **特征解释**：计算时间序列中连续低于均值的最长序列长度。
- **计算公式**：连续低于均值点的最长子序列长度
- **特征类型**：连续性特征
- **适用性**：
  - 检测持续下降或低水平期
  - 识别时间序列中的稳定负偏离
  - 分析数据的抑制期或衰退期
- **示例**：对于序列 [1, 2, 3, 1, 2, 6, 4, 5]，均值为3，longest_strike_below_mean = 2（前两个值或第四和第五个值）

### 61. time_reversal_asymmetry_statistic
- **特征解释**：计算时间序列的时间反转不对称统计量。
- **计算公式**：$\frac{1}{n-2\tau}\sum_{i=0}^{n-2\tau}[x_{i+\tau}-x_{i}][x_{i+\tau+\delta}-x_{i+\tau}]^2$
- **特征类型**：自相关特征
- **适用性**：
  - 检测时间序列的非线性结构
  - 评估时间序列是否具有可逆性
  - 识别具有方向性的因果关系模式
- **示例**：在不可逆非线性系统中，此统计量显著不为零

## 频域特征

### 17. fft_aggregated(x, param)
- **特征解释**：应用快速傅里叶变换(FFT)并聚合频谱数据。
- **计算公式**：对FFT结果应用聚合函数（如均值、方差等）
- **特征类型**：频域特征
- **适用性**：
  - 分析时间序列的频率特性
  - 检测周期性模式
  - 识别信号中的主要频率成分
- **参数**：param - 包含要使用的聚合函数
- **示例**：可以计算FFT系数的均值、方差、偏度等，提供频域分布特征

### 18. fft_coefficient(x, param)
- **特征解释**：计算快速傅里叶变换的系数，提供频域表示。
- **计算公式**：$X_k = \sum_{n=0}^{N-1} x_n e^{-i2\pi kn/N}$
- **特征类型**：频域特征
- **适用性**：
  - 提取特定频率的振幅和相位信息
  - 识别周期性模式的强度和时间偏移
  - 分析复杂信号中的谐波结构
- **参数**：param - 包含要提取的系数索引
- **示例**：提取低频、中频和高频系数，分析不同频段的信号强度

### 55. spkt_welch_density(x, param)
- **特征解释**：应用Welch方法计算时间序列的功率谱密度估计。
- **计算公式**：基于信号分段、加窗和平均的改进功率谱估计
- **特征类型**：频域特征
- **适用性**：
  - 比标准FFT提供更稳定的频谱估计
  - 分析不同频段的能量分布
  - 降低频谱泄漏效应的影响
- **参数**：param - 包含要估计的频带
- **示例**：计算特定频带内的功率谱密度，如低频噪声或特定振动频率

### 15. cwt_coefficients(x, param)
- **特征解释**：应用连续小波变换(CWT)并提取系数。
- **计算公式**：基于小波函数的时间-尺度分解
- **特征类型**：时频特征
- **适用性**：
  - 分析非平稳信号
  - 同时捕捉时间和频率特征
  - 在不同尺度上识别局部模式
- **参数**：param - 包含小波类型、尺度和系数索引
- **示例**：提取特定尺度和位置的小波系数，分析局部频率特性

### 43. number_cwt_peaks(x, n)
- **特征解释**：使用连续小波变换检测时间序列中的峰值数量。
- **计算公式**：基于CWT的峰值检测算法
- **特征类型**：形态特征
- **适用性**：
  - 比简单阈值更鲁棒的峰值检测
  - 可以过滤不同尺度的噪声
  - 识别多尺度结构中的重要峰值
- **参数**：n - 控制检测灵敏度
- **示例**：在心电图数据中检测R峰的数量，忽略小波动

### 44. number_peaks(x, n)
- **特征解释**：计算时间序列中的峰值数量。
- **计算公式**：基于局部极大值的峰值检测
- **特征类型**：形态特征
- **适用性**：
  - 识别时间序列中的峰值事件
  - 分析周期性或突发性模式
  - 计数特征点或关键事件
- **参数**：n - 控制检测灵敏度（窗口大小）
- **示例**：在传感器数据中计算活动爆发的次数

## 信息论特征

### 5. approximate_entropy(x, m, r)
- **特征解释**：计算时间序列的近似熵，衡量时间序列的复杂度和不规则性。
- **计算公式**：基于重复模式的条件概率估计
- **特征类型**：复杂度特征
- **适用性**：
  - 量化时间序列的不规则性
  - 区分随机信号和确定性信号
  - 分析生理信号和金融数据的复杂性
- **参数**：m - 嵌入维度；r - 相似性阈值
- **示例**：规则心跳的近似熵低于不规则心跳

### 52. sample_entropy(x)
- **特征解释**：计算时间序列的样本熵，类似于近似熵，但有更好的统计特性。
- **计算公式**：与近似熵类似，但排除自匹配
- **特征类型**：复杂度特征
- **适用性**：
  - 对短时间序列更稳健的复杂度测量
  - 相比近似熵有更低的偏差
  - 在生物医学信号处理中广泛使用
- **示例**：高度不规则信号的样本熵较高，规则或周期性信号的样本熵较低

## 位置特征

### 19. first_location_of_maximum(x)

### 20. first_location_of_minimum(x)

  - 分析谷值事件的时间分布

### 28. last_location_of_maximum(x)

- **示例**：对于序列 [1, 5, 3, 5, 2]，last_location_of_maximum = 3（索引从0开始）

### 29. last_location_of_minimum(x)
- **特征解释**：找到时间序列中最后一个最小值出现的位置。
- **计算公式**：$\text{argmin}_i(x_i)$（最后一次出现）
- **特征类型**：位置特征

  - 与first_location_of_minimum结合分析谷值的持续性

## 模型系数特征

### 6. ar_coefficient(x, param)
- **特征解释**：计算自回归(AR)模型的系数，表示时间序列与其过去值之间的关系。
- **计算公式**：通过求解Yule-Walker方程得到AR系数
- **特征类型**：模型参数特征
- **适用性**：
  - 建立时间序列的自回归表示
  - 评估不同滞后对当前值的影响
  - 提供数据生成过程的参数化描述
- **参数**：param - 包含AR模型阶数和系数索引
- **示例**：一阶AR模型系数接近1表示高度的时间相关性

### 7. augmented_dickey_fuller(x, param)
- **特征解释**：执行增广迪基-富勒检验，用于检测时间序列的平稳性。
- **计算公式**：基于单位根检验的统计量及其p值
- **特征类型**：统计检验特征
- **适用性**：
  - 确定时间序列是否平稳
  - 评估是否需要差分处理
  - 为ARIMA建模提供指导
- **参数**：param - 包含检验配置（如滞后选择）
- **示例**：小p值表示可以拒绝"存在单位根"的原假设，即时间序列是平稳的

### 21. friedrich_coefficients(x, param)
- **特征解释**：计算基于多项式拟合的弗里德里希系数，用于表示时间序列的非线性动态特性。
- **计算公式**：基于Langevin方程的多项式拟合系数
- **特征类型**：模型参数特征
- **适用性**：
  - 捕捉时间序列的非线性动态特性
  - 在混沌系统分析中有应用
  - 区分不同类型的随机过程
- **参数**：param - 包含多项式阶数、窗口大小和系数索引
- **示例**：高阶系数显著不为零表示存在复杂的非线性动力学

### 31. linear_trend(x, param)
- **特征解释**：计算时间序列的线性趋势特征，包括斜率、截距和预测值等。
- **计算公式**：通过最小二乘法拟合线性模型y = at + b
- **特征类型**：趋势特征
- **适用性**：
  - 量化时间序列的整体趋势
  - 预测未来值的基础模型
  - 去除长期趋势进行残差分析
- **参数**：param - 包含属性选择（斜率、截距等）
- **示例**：正斜率表示上升趋势，负斜率表示下降趋势

### 4. agg_linear_trend(x, param)
- **特征解释**：将时间序列分成多个区块，对每个区块计算线性回归，然后对回归属性应用聚合函数。
- **计算公式**：在分段窗口上进行线性回归，再聚合
- **特征类型**：趋势特征
- **适用性**：
  - 分析不同时间尺度上的趋势
  - 检测趋势的变化模式
  - 比较不同区块的趋势强度
- **参数**：param - 包含区块长度、属性选择（斜率、截距等）和聚合函数
- **示例**：可以计算所有区块斜率的标准差，评估趋势稳定性

### 34. max_langevin_fixed_point(x, r, m)
- **特征解释**：计算时间序列的最大朗之万固定点，这是一个基于非线性动力学的特征。
- **计算公式**：基于Langevin方程模型的固定点估计
- **特征类型**：非线性动力学特征
- **适用性**：
  - 识别动态系统的稳定状态
  - 分析吸引子和平衡点特性
  - 在物理和金融系统分析中有应用
- **参数**：r - 半径参数；m - 二项式系数数量
- **示例**：在混沌系统中，固定点数量和特性揭示了底层动力学

### 60. symmetry_looking(x, param)
- **特征解释**：评估时间序列在给定参数下的对称性。
- **计算公式**：基于时间序列与其镜像之间的相似性测量
- **特征类型**：形态特征
- **适用性**：
  - 检测时间序列的对称模式
  - 识别周期性信号的特征
  - 分析信号的形态特性
- **参数**：param - 包含评估对称性的配置
- **示例**：完全对称的周期信号具有最高的对称性得分

## 复杂度特征

### 12. cid_ce(x, normalize)
- **特征解释**：计算时间序列的复杂度不变形状描述符。
- **计算公式**：基于相邻点差分的平方和
- **特征类型**：复杂度特征
- **适用性**：
  - 衡量时间序列的复杂度或不规则性
  - 与信号能量无关的形状描述
  - 比较不同尺度时间序列的复杂性
- **参数**：normalize - 是否进行归一化处理
- **示例**：高度不规则或噪声信号具有较高的CID值

### 16. energy_ratio_by_chunks(x, param)
- **特征解释**：将时间序列分成若干个区块，计算每个区块能量占总能量的比例。
- **计算公式**：$\frac{\sum_{i \in chunk}x_i^2}{\sum_{i=1}^{n}x_i^2}$
- **特征类型**：能量分布特征
- **适用性**：
  - 分析能量在时间上的分布模式
  - 检测突发活动或能量集中期
  - 评估信号能量的时域不均匀性
- **参数**：param - 包含分块方法和数量
- **示例**：均匀分布的信号在各区块上能量比例接近，突发信号则在特定区块能量比例高

### 53. set_property(key, value)
- **特征解释**：设置特征提取函数的属性，是一个辅助函数。
- **计算公式**：不适用（非特征提取函数）
- **特征类型**：元功能
- **适用性**：
  - 配置特征提取过程
  - 设置特征属性的元数据
  - 用于内部控制和参数传递
- **参数**：key - 属性名称；value - 属性值
- **示例**：用于标记或配置特征计算方法的内部状态

### 2. absolute_sum_of_changes(x)
- **特征解释**：计算相邻时间点间绝对差值的总和，衡量时间序列的波动程度。
- **计算公式**：$\sum_{i=1}^{n-1} |x_{i+1} - x_i|$
- **特征类型**：变化率特征
- **适用性**：
  - 衡量时间序列的总体变化幅度
  - 评估数据的波动性或不稳定性
  - 区分平稳和非平稳序列
- **示例**：对于序列 [1, 3, 2, 4]，absolute_sum_of_changes = |3-1| + |2-3| + |4-2| = 2 + 1 + 2 = 5

### 37. mean_abs_change(x)
- **特征解释**：计算时间序列中相邻点间绝对差值的平均值。
- **计算公式**：$\frac{1}{n-1}\sum_{i=1}^{n-1} |x_{i+1} - x_i|$
- **特征类型**：变化率特征
- **适用性**：
  - 衡量时间序列的平均变化幅度
  - 对比不同长度序列的波动性
  - 评估信号的平均不稳定性
- **示例**：对于序列 [1, 3, 2, 4]，mean_abs_change = 5/3 ≈ 1.67

### 38. mean_change(x)
- **特征解释**：计算时间序列中相邻点间差值的平均值（保留正负号）。
- **计算公式**：$\frac{1}{n-1}\sum_{i=1}^{n-1} (x_{i+1} - x_i)$
- **特征类型**：变化率特征
- **适用性**：
  - 识别整体上升或下降趋势
  - 评估平均变化方向和大小
  - 作为线性趋势的简化估计
- **示例**：对于序列 [1, 3, 2, 4]，mean_change = (2 + (-1) + 2)/3 = 1

### 39. mean_second_derivative_central(x)
- **特征解释**：计算时间序列的中央二阶导数平均值。
- **计算公式**：$\frac{1}{n-2}\sum_{i=1}^{n-2} (x_{i+2} - 2x_{i+1} + x_i)$
- **特征类型**：变化率特征
- **适用性**：
  - 衡量时间序列的平均加速度
  - 检测变化率的变化
  - 识别拐点和趋势变化
- **示例**：对于序列 [1, 3, 2, 4]，mean_second_derivative_central = ((4-2×2+1)/1) = 1

### 11. change_quantiles(x, ql, qh, isabs, f_agg)
- **特征解释**：计算时间序列在指定的分位数范围[ql, qh]内的变化。
- **计算公式**：对范围内数据点应用变化计算和聚合函数
- **特征类型**：变化率特征
- **适用性**：
  - 分析特定分位数范围内的变化特性
  - 过滤极值影响，关注特定数据区间
  - 计算动态范围内的变化统计量
- **参数**：ql - 下分位数；qh - 上分位数；isabs - 是否使用绝对变化；f_agg - 聚合函数
- **示例**：可计算中间50%数据点（25%-75%分位数）的平均绝对变化

### 42. number_crossing_m(x, m)
- **特征解释**：计算时间序列穿过阈值m的次数。
- **计算公式**：相邻点一个大于m一个小于m（或等于）的次数
- **特征类型**：形态特征
- **适用性**：
  - 检测时间序列在特定水平的波动频率
  - 分析信号与基准线的交叉模式
  - 识别状态变化或阈值穿越事件
- **参数**：m - 阈值水平
- **示例**：对于序列 [1, 3, 2, 4]，m=2.5，number_crossing_m = 2（在第一和第三个间隔穿越）

### 22. has_duplicate(x)
- **特征解释**：检测时间序列是否包含重复值，返回布尔值。
- **计算公式**：len(set(x)) < len(x)的布尔结果
- **特征类型**：结构特征
- **适用性**：
  - 检测数据是否存在重复
  - 识别潜在的数据质量问题
  - 用作数据预处理检查
- **示例**：对于序列 [1, 2, 2, 3]，has_duplicate = True

### 23. has_duplicate_max(x)
- **特征解释**：检测时间序列中最大值是否重复出现，返回布尔值。
- **计算公式**：最大值出现次数 > 1的布尔结果
- **特征类型**：结构特征
- **适用性**：
  - 检测峰值是否独特
  - 识别多个相同的极大值
  - 分析最大值的分布特征
- **示例**：对于序列 [1, 3, 2, 3]，has_duplicate_max = True

### 24. has_duplicate_min(x)
- **特征解释**：检测时间序列中最小值是否重复出现，返回布尔值。
- **计算公式**：最小值出现次数 > 1的布尔结果
- **特征类型**：结构特征
- **适用性**：
  - 检测谷值是否独特
  - 识别多个相同的极小值
  - 分析最小值的分布特征
- **示例**：对于序列 [1, 3, 1, 2]，has_duplicate_min = True

### 46. percentage_of_reoccurring_datapoints_to_all_datapoints(x)
- **特征解释**：计算重复出现的数据点占总数据点的百分比。
- **计算公式**：$\frac{\text{重复出现的数据点数}}{\text{总数据点数}}$
- **特征类型**：结构特征
- **适用性**：
  - 识别重复或周期性模式

### 47. percentage_of_reoccurring_values_to_all_values(x)
- **特征解释**：计算重复出现的值占总值的百分比。
- **计算公式**：$\frac{\text{重复出现的唯一值数量}}{\text{唯一值总数}}$
- **特征类型**：结构特征
- **适用性**：
  - 评估唯一值的重复出现率
  - 与percentage_of_reoccurring_datapoints_to_all_datapoints互补
  - 分析数据值的重复模式
- **示例**：对于序列 [1, 2, 2, 3, 1]，唯一值为[1,2,3]，重复出现的是[1,2]，因此比例为2/3≈0.67

### 57. sum_of_reoccurring_data_points(x)
- **特征解释**：计算重复出现的数据点值的总和。
- **计算公式**：重复值的数据点之和
- **特征类型**：结构特征
- **适用性**：
  - 量化重复值的总贡献
  - 分析重复模式的强度
  - 检测关键重复值的影响
- **示例**：对于序列 [1, 2, 2, 3, 1]，sum_of_reoccurring_data_points = 1 + 1 + 2 + 2 = 6

### 58. sum_of_reoccurring_values(x)
- **特征解释**：计算重复出现的值的总和。
- **计算公式**：重复出现的唯一值之和
- **特征类型**：结构特征
- **适用性**：
  - 与sum_of_reoccurring_data_points互补
  - 不考虑重复次数的重复值贡献
  - 评估重复出现值的大小
- **示例**：对于序列 [1, 2, 2, 3, 1]，重复的唯一值是1和2，因此sum_of_reoccurring_values = 1 + 2 = 3

### 27. large_standard_deviation(x, r)
